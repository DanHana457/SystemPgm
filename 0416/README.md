# Linux System Study

## 학습 내용

### 파일 권한 관리

리눅스의 파일 권한 관리 방식에 대해 학습하였다.

- `chmod()`
  - 경로(path)를 기준으로 파일 권한 변경

- `fchmod()`
  - 파일 디스크립터(fd)를 기준으로 파일 권한 변경

---

### 파일 시간 관리

파일 시간 정보를 변경하는 방법에 대해 학습하였다.

- `utime()`
  - 파일의 시간 정보 수정

---

### touch.c

`touch` 명령어의 동작 방식과 관련된 내용을 학습하였다.

- 파일 생성
- 파일 시간 갱신

---

### 리눅스 파일 시스템

리눅스 파일 시스템 구조에 대해 학습하였다.

#### 주요 내용

- 트리(Tree) 구조 기반 파일 시스템
- inode 기반 파일 관리 방식

#### 주요 디렉토리

| 디렉토리 | 설명 |
|---|---|
| `/` | 루트 디렉토리 |
| `/home` | 사용자 홈 디렉토리 |
| `/bin` | 기본 실행 파일 저장 |
| `/etc` | 시스템 설정 파일 |
| `/tmp` | 임시 파일 저장 |
| `/usr` | 사용자 프로그램 및 라이브러리 |

---

## 정리

- 리눅스는 파일 권한을 통해 접근을 관리한다.
- `chmod()` 와 `fchmod()` 는 권한 변경 방식에 차이가 있다.
- `utime()` 을 사용하여 파일 시간 정보를 변경할 수 있다.
- 리눅스 파일 시스템은 inode 기반으로 동작한다.
