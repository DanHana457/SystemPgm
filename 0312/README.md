# Linux System Study

## 학습 내용

### 명령어 도움말 확인

- `man` 명령어를 사용하여 리눅스 명령어 매뉴얼 확인
- `info` 명령어를 통해 상세한 GNU 문서 확인
- `명령어 --help` 옵션으로 간단한 사용법 확인

### 시스템 및 패키지 관리

- `passwd root`
  - root 계정 비밀번호 설정

- `apt-get update`
  - 패키지 목록 업데이트

- `apt install gcc`
  - gcc 컴파일러 설치

## 디렉토리 구조 및 이동

### 디렉토리 의미

- `.` : 현재 디렉토리
- `..` : 부모 디렉토리
- `~` : Home 디렉토리
- `/` : Root 디렉토리

### 사용한 명령어

- `cd`
  - 디렉토리 이동

- `cd ~`
  - 홈 디렉토리로 이동

- `pwd`
  - 현재 작업 중인 디렉토리 위치 확인

## 파일 및 디렉토리 확인

### ls 명령어

- `ls`
  - 파일 및 디렉토리 목록 출력

- `ls -l`
  - 파일 권한, 소유자, 수정 시간 등 상세 정보 출력

- `ls -al`
  - 숨김 파일을 포함한 전체 목록 출력

- `ll`
  - `ls -l` 형태의 별칭(alias)

### alias

- 자주 사용하는 명령어를 별칭으로 등록하여 사용 가능
