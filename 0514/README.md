# Linux System Study

## 학습 내용

### 네트워크 구성

- LAN(Local Area Network)
- Router
- Gateway
- Wireless Access Point(WAP)

---

### 인터넷

- TCP/IP 프로토콜
- IP 주소
- 호스트명(hostname)
- DNS(Domain Name System)

---

## 정리

- 인터넷은 TCP/IP 프로토콜을 이용하여 통신한다.
- IP 주소와 호스트명을 이용하여 네트워크 장치를 구분한다.
- 네트워크 구성 요소와 인터넷 동작 방식에 대해 학습하였다.
- 원격 접속 관련 내용을 학습하였다.
