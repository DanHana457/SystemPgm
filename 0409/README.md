# Linux System Study

## 학습 내용

- 시스템 호출(System Call)의 개념 학습
  - 사용자 프로그램이 커널 기능을 사용할 때 사용하는 인터페이스

- 파일 관련 시스템 호출 학습
  - `open()`
  - `close()`
  - `read()`
  - `write()`

- 파일 디스크립터(File Descriptor)의 개념 학습
  - 운영체제가 열린 파일을 구분하기 위해 사용하는 번호

- `lseek()` 함수를 이용한 파일 위치 이동 학습

- 하드 링크(Hard Link)와 심볼릭 링크(Symbolic Link)의 차이 학습

- 파일 생성 및 읽기/쓰기 동작 과정 학습
